    Cómo está armado

    Una ruta distinta cuenta como una fuente distinta.

    El catálogo proviene de fuentes/catalogo_fp.md. Solo se eliminan URLs exactamente repetidas: si una institución tiene varias secciones, documentos o herramientas útiles, cada URL permanece como ficha independiente con su propia descripción.

    La ronda de revisión es el subconjunto ordenado de fuentes marcadas como críticas: el recorrido mínimo de cada día. La bitácora guarda los hallazgos del día por fuente y se exporta en Markdown.

    Para añadir o quitar fuentes, edita el archivo Markdown y ejecuta node scripts/generar_datos.mjs.
